# Community code of conduct

Cadenza's community should be a focused, respectful place to improve an
educational music tool. This applies to issues, pull requests, reviews,
discussions, and other project spaces.

## Expected behavior

- Be considerate, specific, and patient with people of different experience
  levels, backgrounds, identities, and musical traditions.
- Critique code, evidence, and product decisions rather than people.
- Respect privacy and copyright; do not post private profiles, device logs with
  personal data, or scores you cannot redistribute.
- Give credit, disclose relevant conflicts, and correct mistakes openly.
- Accept maintainer decisions about scope and safety without harassment.

## Unacceptable behavior

Harassment, threats, discriminatory language, sexualized attention, doxxing,
deliberate disruption, copyright abuse, and publishing another person's private
information are not tolerated.

## Reporting and enforcement

For ordinary moderation, contact the repository owner through their GitHub
profile with the relevant link and context. Do not use a public thread if doing
so would expose private information. Security vulnerabilities follow
`SECURITY.md` instead.

Maintainers may edit or remove content, lock discussions, reject contributions,
or temporarily or permanently restrict participation. Decisions should be
proportionate, documented privately where practical, and made without
retaliation. This policy covers project-controlled spaces; platform operators
control enforcement on GitHub itself.
