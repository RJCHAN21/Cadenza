# Support

Cadenza is pre-release volunteer software. There is no service-level agreement,
guaranteed response time, individual music instruction, or guarantee that a
particular score, MIDI device, or Windows configuration will work.

Before requesting help:

1. Read `README.md` and `docs/LIMITATIONS.md`.
2. Use the current default branch and the .NET SDK selected by `global.json`.
3. Run `./scripts/Validate.ps1` from a clean clone.
4. Reduce score-specific problems to a small original, redistributable fixture.
5. Remove names, local paths, device serials, private scores, and profile data
   from logs or screenshots.

Use the bug-report template for reproducible defects and the feature-request
template for scoped proposals. Use the private process in `SECURITY.md` for
vulnerabilities. Questions about professional assessment, curriculum design,
or medical accessibility needs are outside the project's support scope.
