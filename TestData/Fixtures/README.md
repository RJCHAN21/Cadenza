# Deterministic fixtures

These fixtures were composed specifically for Cadenza and do not reproduce a
copyrighted song or third-party score.

`cadenza-timeline.musicxml` covers a two-staff chord, a forward/backward
repeat, first and second endings, tempo and meter changes, a tie, a rest, and a
final barline. Its independent contract is recorded in
`cadenza-timeline.expected.json`: five written measures and 18 written beats
expand to the performance order `1, 2, 3, 1, 2, 4, 5` and 26 performance
beats.

`cadenza-timeline.mxl` is the deterministic compressed form generated by
`scripts/Generate-TestFixtures.ps1`. The MIDI files in this directory are also
generated by that script; each malformed file isolates one parser boundary.
