# Changelog

All notable changes will be documented here. Cadenza has not made a stable
release and does not yet promise semantic-versioning compatibility.

## Unreleased

- Removed tracked build output and machine/song-specific startup assumptions.
- Added original deterministic MusicXML, MXL, and MIDI regression fixtures.
- Unified parser, simulation, and renderer checks around Cadenza's authoritative
  repeat/volta occurrence plan.
- Added bounded malformed-MIDI handling and focused rejection fixtures.
- Added a .NET 8 solution, clean-clone validation script, and complete CI path.
- Added contributor, security, conduct, support, architecture, limitation, and
  third-party documentation.
- Licensed Cadenza-authored project work under GPL-3.0-only and documented the
  separate terms that continue to apply to bundled third-party components.
